# Nails App (mock)

Frontend-only Angular 21 app for nail masters to sell their services, running on mock data.

```bash
npm install
npm start          # http://localhost:4200
npm run check      # typecheck + lint + tests
```

Stack: Angular 21 (zoneless, signals), NgRx SignalStore, SCSS design tokens, Jest, ESLint, Prettier.
See [CLAUDE.md](CLAUDE.md) for architecture and conventions.
